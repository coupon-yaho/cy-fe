# 쿠폰 야~호 — 프론트엔드 구축 계획

PRD의 선착순 쿠폰 발급 시스템을 화면으로 구현합니다. 데이터는 전부 목업이며, 나중에 스프링 `/api/v1/*` 백엔드로 갈아끼울 수 있도록 API 레이어를 한 파일로 분리합니다.

## 브랜드 & 디자인
- 업로드한 로고(`logo-a-full.png` 가로형, `logo-b-keyvisual.png` 키비주얼)를 헤더/랜딩 히어로에 사용하고, 로고에서 딴 파비콘을 설정합니다.
- 팔레트: 네이비 잉크 (`#0f1b3d` / `#1e3a5f` / `#3b6fa0` / `#e8edf3`), 쿠폰 티켓 모티프(점선 절취선, 반원 노치), 한국어 가독 서체. 다크모드는 관리자 관제 화면 포함 전 화면 지원.

## 페이지 구성

### 1) 랜딩 `/`
히어로(키비주얼 + 다음 브랜드 데이 카운트다운), 브랜드 12개 그리드, 등급 혜택 안내(VIP/GOLD/SILVER/WELCOME), 발급 3단계 설명, 사용자/관리자 진입 CTA.

### 2) 인증 (목업) `/login`, `/signup`
아이디 아무거나 입력 → 등급·역할 선택(사용자/관리자)해서 로그인. 목 JWT 클레임(`sub`, `grade`, `role`)을 localStorage에 저장, 데모 계정 원클릭 버튼 제공.

### 3) 사용자 페이지
- `/events` — 참여 가능한 브랜드 데이 목록. 내 등급 기준 필터(자격 미달은 잠금 배지), 상태 배지 `SCHEDULED/OPEN/CLOSED`, 남은 재고 게이지.
- `/events/$couponId` — 이벤트 상세 + 발급 버튼. 오픈 전 카운트다운, 오픈 시 입장 판정 → 대기열 화면(순번·예상 시간 1초 폴링, 진행 바) → 발급 성공/실패 결과. PRD §11.2 코드별 안내 문구를 그대로 반영(`STOCK_EXHAUSTED`, `ALREADY_ISSUED`, `GRADE_NOT_ELIGIBLE`, `NOT_OPENED`, `COUPON_CLOSED` 등).
- `/my/coupons` — 내 쿠폰 지갑. 티켓 카드 형태, 상태별 탭(ISSUED/USED/CANCELLED/EXPIRED), 사용·사용취소·취소 액션(멱등키 생성 포함), 할인 정책 3종 표시(정률+상한 / 정액 / 데이터).
- 알림은 목업: 액션 시 토스트 + 헤더 알림 벨(목 알림 목록).

### 4) 관리자 페이지 (사이드바 레이아웃, 역할 가드)
- `/admin` — **화면 ① 쿠폰 운영**: 상단 stat 4종(잔여 재고, 진행률, 초당 발급, 대기 인원), 재고 소진 곡선, 상태별 보유량 추이, 등급별 발급 분포, 하단 발급 이벤트 스트림 + 상태 전이 스트림 테이블(PII 마스킹).
- `/admin/system` — **화면 ② 시스템 관제**: 초과 발급 0 경보, p99, Circuit Breaker 배지 3종, 응답코드 rate, 응답시간 분위, 리소스 사용률, 대기열 모드 밴드, Redis↔DB 격차(버전별 라벨 v1 비활성/v2 drift/v3 lag).
- `/admin/analytics` — **화면 ③ 분석·비교**: v1/v2/v3 벤치마크 비교표·차트, 브랜드별 전환율, 요일×시간 히트맵, 등급 분포, 검증 배치 리포트.
- `/admin/coupons` — 쿠폰 CRUD: 목록(필터·검색·페이지네이션), 생성/수정 다이얼로그(브랜드, 정책 유형+값, 재고, open/close, 참여 등급 비트마스크 체크박스), 삭제/마감.
- `/admin/brands` — 브랜드 CRUD 12개.
- `/admin/schedules` — 브랜드 데이 스케줄 CRUD(매월 N번째 요일, 시각, 지속시간, 회차당 재고, 참여 등급).
- 공통: 시간 범위 `1m/5m/15m`, 갱신 주기 `1s/5s/off` 컨트롤.

## 기술 사항
- TanStack Start 파일 기반 라우팅, 각 라우트에 고유 `head()` 메타.
- 목 데이터 레이어: `src/lib/api/*` — PRD §11.1 경로와 동일한 시그니처의 함수로 감싸고 내부는 in-memory 스토어 + 지연/랜덤 실패 시뮬레이션. 실제 연동 시 이 파일들만 fetch로 교체.
- 상태: TanStack Query(폴링·무효화), 목 스토어는 모듈 싱글턴 + localStorage 지속.
- 차트: Recharts. 실시간 시계열은 목 티커가 1초마다 데이터 포인트 생성.
- 시드: 브랜드 12개, 쿠폰 템플릿·쿠폰, 발급 이력 샘플, 통계 집계값(300만 건 규모를 대표하는 사전 집계 수치).
- 인증 가드: `role: ADMIN` 아니면 `/admin/*` 접근 시 랜딩으로 리다이렉트.
- 백엔드는 붙이지 않습니다(전부 클라이언트 목업).
