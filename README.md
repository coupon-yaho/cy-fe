# Coupon Charm

로고와 prd야 이걸 바탕으로 필요한 페이지들을 제작 해줘. 페이지는 쿠폰 crud, 통계 등등을 하는 관리자 페이지와 쿠폰 발행해서 사용하는 사용자 페이지가 있어야해. 또한 간단한 랜딩 페이지가 있었으면해. 로그인과 회원가입 같은 것은 mocking처리, 알림도 mocking처리할거야. 이런점 고려해서 진행해줘.
